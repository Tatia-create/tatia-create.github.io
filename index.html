Weather · Temperature · Clothing

9/25–10/6 天气 & 穿衣速查

以下为这段时间的历史气候参考，实际出发前仍需看短期预报。Rockies 海拔高、昼夜温差大，9月底已经可能遇到降雪或结冰。

Vancouver 温哥华

约 11–18°C

温和、可能有雨。长裤 + T恤/薄针织 + 轻薄防水外套即可。

Banff 班夫

约 0–16°C

早晚很冷、温差明显。保暖内层 + 抓绒/薄羽绒 + 防风防水外壳。

Lake Louise 露易丝湖

约 -2–14°C

清晨可能低于0°C。看湖或徒步建议薄羽绒、帽子和手套。

Icefields Parkway 冰原大道

约 -3–10°C

风大、变化快，可能有雪/结冰。薄羽绒 + 防水硬壳，车内备额外保暖层。

Toronto 多伦多

约 8–18°C

典型初秋。长裤 + 长袖/针织 + 轻外套即可。

Montréal 蒙特利尔

约 4–13°C

早晚明显偏凉，可能下雨。毛衣/针织 + 中等厚度外套。

Québec City 魁北克城

约 2–12°C

比蒙特利尔更凉。毛衣/抓绒 + 中等外套，郊区建议随身带薄羽绒。

最简单的打包原则：整趟采用“洋葱式分层”。城市秋装即可；Rockies 额外准备薄羽绒或抓绒、防风防水外壳、徒步鞋、帽子和手套。

OPTIONAL BRANCH · GASPÉ

Gaspé 加斯佩半岛 · 不自驾能不能去？

可以，但公共交通明显比 Banff 稀疏，且时间成本高。因此它更适合单独留 4–5 晚，而不是硬塞进当前12天。

方案 A · 全公交慢旅行

Québec City / Montréal → Orléans Express → Gaspé / Percé。到 Gaspé 后用 RÉGÎM 区域公交进入 Forillon 周边；RÉGÎM 21线经过 Penouille、Cap-des-Rosiers、Fort Péninsule 等入口点。

缺点：班次少、换乘受工作日限制；进入 Forillon 后没有园内公共交通，需步行或骑车。

方案 B · 飞机 + 地方公交

YUL → YGP 飞 Gaspé，再搭 RÉGÎM / taxi，之后用 Orléans Express 去 Percé。节省长途巴士时间，但机票常偏贵，地方 taxi 也应提前约。

不建议铁路：Matapédia–Gaspé 客运仍未恢复，工程计划到2026年底左右才可能具备恢复条件。

结论：无车可以去 Gaspé，但不像 Banff 那样“公共交通成熟”。若以后专门给 Gaspé 4–5晚，我会按 Gaspé 2晚 + Forillon 1日 + Percé 2晚重新做一套无车路线。

Niagara真实游客高评价游船，比只在岸边看更值得。Version B 固定加入 Voyage to the Falls。

Rockies 总原则：不把每天锁死。Peyto / Moraine / Larch 对天气敏感，行程要允许根据能见度互换；个人体验用于判断“值不值、多久”，2026官方交通用于判断“能不能、怎么买”。
